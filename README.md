# This repository is retired

This repository is no longer maintained. We will maintain SQL Server container resources in the [Azure SQL Database Container repository](https://github.com/microsoft/azure-sql-database-container).

Please raise new issues and feature requests in that repository: [microsoft/azure-sql-database-container/issues](https://github.com/microsoft/azure-sql-database-container/issues).

Existing issues in this repository will be reviewed and closed after being resolved here or ported to the new repository, as appropriate.
